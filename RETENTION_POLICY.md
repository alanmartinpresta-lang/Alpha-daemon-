# A1.8 CLEAN — retention policy

The previous multi-Alpha checkpoints and experiment result artifacts are NOT part
of the operational Genesis package.

Retained:
- authoritative AIRE runtime code;
- Alpha body/sensors/effectors/metabolism/homeostasis/learning/memory code;
- validated world modifications carried by that runtime;
- canonical single-Alpha Genesis runner;
- Genesis readiness documentation.

Removed from the operational package:
- ALPHA_*.aire checkpoints;
- BIOME_REV_*.json;
- HYDRO_*.json;
- INTERVENTION_*.json;
- LEARN_*.json;
- REV_*.json;
- thermal experiment result files;
- multi-Alpha continuation scripts/reports;
- temporary validation harnesses.

Scientific record:
The historical results should be retained separately as an archive if traceability
is desired. They are not required for the execution of the single Alpha Genesis.

Important:
Do NOT delete the last frozen V203/A1.8 backup until the first Genesis run has
been successfully checkpointed and independently verified.
