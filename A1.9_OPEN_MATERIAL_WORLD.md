# A1.9 — Open Material World

## Purpose
Give a solitary Alpha the minimum physical affordances needed to discover
object manipulation without giving it a construction goal, object names,
recipes, technology concepts, or rewards for making things.

## Added
- 8 anonymous physical material objects per fresh world.
- Each has only mass, rigidity, friction and conductivity.
- Raw proximity/contact is exposed to Alpha.
- Primitive actions: push, grasp, release.
- A grasped object follows Alpha's physical position.
- Released objects retain their physical state.
- Push imparts a simple physical impulse.

## Deliberately NOT added
- no "tool" / "house" / "weapon" labels;
- no semantic object categories;
- no crafting recipes;
- no construction reward;
- no "explore/build/create" objective;
- no action telling Alpha which material is useful;
- no scripted sequence of discoveries.

## Validation
- 300-step autonomous smoke: PASS; Alpha autonomously selected grasp/push/release
  among the existing homeostatic policy actions.
- 1000-step checkpoint round-trip: PASS; 8 objects and carried-object state survive
  save/load and Alpha remains alive.

## Interpretation
The first 300-step result is NOT evidence of invention. It only demonstrates that
the new physical affordances are reachable by the existing autonomous policy.
Genesis 2 should be run from a fresh checkpoint and analyzed without intervention.
